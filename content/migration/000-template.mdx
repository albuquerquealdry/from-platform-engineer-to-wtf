Open with what you were actually doing. No throat-clearing, no "in this post I will".
The first paragraph should tell someone whether this entry is relevant to them.

## What I was trying to do

Plain prose. The body is set in a serif at a comfortable reading size, so paragraphs can
breathe. Inline `code` looks like this, and [links](/logs/) are underlined in the accent colour.

Root-relative links like `/logs/` get the site base added automatically at build time, so
write them the natural way.

## What I didn't know

- Bullet lists work
- So do numbered lists
- Keep them short; prose carries more

> Blockquotes are for the sentence you want someone to remember, or for quoting
> something you got wrong earlier.

## What I built

Fenced code blocks get build-time highlighting, a language label and a copy button:

```python
THRESHOLD = 0.02

def promote(candidate: Metrics, incumbent: Metrics) -> bool:
    if candidate.auc < incumbent.auc - THRESHOLD:
        log.warning("blocked: auc %.4f < %.4f", candidate.auc, incumbent.auc)
        return False
    return True
```

A fenced block with no language stays plain — good for ASCII diagrams and terminal output:

```
p50   840 ms
p95  2100 ms
p99  6400 ms
```

## What I learned

Keep it honest. "I still don't know" is a valid ending and ages better than a conclusion
you can't defend.
