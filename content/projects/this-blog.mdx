Static site, Markdown files in git, zero JavaScript by default. A new entry is
`npm run new`, type, commit. The stack is documented in the repo README; the
interesting choice is everything that is *not* here: no CMS, no database, no
analytics beyond a feedback widget.

It also eats its own cooking: the migration series documents work, the notes
collection captures the raw material, and entries graduate from one to the other.
